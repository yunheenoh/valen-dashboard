배포 & 설정 가이드
이 대시보드를 팀과 공유하는 방법
1
Google Apps Script 설정 (데이터 공유 서버)
1. script.google.com 접속 → 새 프로젝트 생성
2. code.gs 파일에 아래 코드 전체 붙여넣기
3. 상단 "배포" → "새 배포" → 유형: 웹 앱
4. "다음 사용자로 실행": 나 / "액세스 권한": 모든 사용자
5. 배포 후 나오는 웹 앱 URL을 복사
/* Google Apps Script 코드는 gas.gs 파일을 참고하세요 */
2
index.html의 API URL 교체
index.html 파일 상단의 GAS_URL 변수에 복사한 웹 앱 URL을 붙여넣으세요.
const GAS_URL = "여기에_웹앱_URL_붙여넣기";
3
GitHub Pages로 배포
1. github.com → 새 저장소 생성 (예: valen-dashboard)
2. index.html, gas.gs 파일 업로드
3. Settings → Pages → Branch: main → Save
4. 생성된 URL (예: yourname.github.io/valen-dashboard) 파트장들에게 공유
4
슬랙 리마인더 설정
파트장 DM 또는 채널에서 아래 명령어를 입력하세요. 매주 수요일 오후 2시 자동 발송.
/remind @박현주 @이주현 "오늘 오후 6시까지 대시보드 수치 입력 부탁드려요 → [URL]" every Wednesday at 2pm
